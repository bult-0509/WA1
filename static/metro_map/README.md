# 10分钟边流量动画资源

此目录由用户提供的四个文件整合而成：`metro_map.html`、`stations.js`、`edges.js` 和 `data_flow_edges.js`。项目保留其数据内容，调整了页面文案、异常日规则和离线资源路径。

- `stations.js`：302个站点及坐标、邻接信息。
- `edges.js`：349条无向邻接边。
- `data_flow_edges.js`：2017年5月1日至12日共12天、06:00—23:00的10分钟边流量。5月4日、8日和9日属于计数缺损日，页面不提供选择，其余9天参与动画。
- `metro_map.html`：Leaflet动画页面，由Streamlit“站点空间—10分钟动画”视图嵌入。

附件没有提供边流量的生成脚本或公式，因此项目将其标记为预生成结果，不把边值解释为真实OD、方向客流或去重乘客数。“边流量合计”只是同一时段各边数值相加。

页面不加载在线瓦片或脚本。Leaflet 1.9.3固定在`vendor/leaflet/`，许可文本与代码一起保留；阿里妈妈方圆体从上一级`static/fonts/`读取。
