# MetroFlow: Human Mobility Datasets in the Complex Metro System of Shanghai

MetroFlow is an open-sourced, city-scale metro flow dataset, covering the period of May-August 2017 and 302 metro stations in Shanghai, China.  This repository contains seven files:



- Station Attributes Data (**stationInfo.csv**)
  
- Metro Station Inflow and Outflow Data (**metroData\_InOutFlow.csv**)
  
- Metro Station Origin-Destination Flow Data (**metroData\_ODFlow.csv**)
  
- Meta Data (**travelTime.pkl, travelDis.pkl, shanghai\_weatherHourly.csv, work\_calendar.csv**)

***

The detailed description of this data repository is presented in **MetroFlow: Human Mobility Datasets in the Complex Metro System of Shanghai**.



 Jupyter notebooks for dataset organization and analyses are open-sourced at https://github.com/Ariza-Sun/MetroFlow.
